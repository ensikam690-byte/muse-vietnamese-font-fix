# Muse Vietnamese Font Fix

Extension nhẹ giúp sửa lỗi hiển thị dấu tiếng Việt bị lệch nét, dính chữ trên **Muse của Meta** (cả giao diện web `muse.ai` lẫn khung chat trong Side Panel của extension Muse gốc).

Vì hoạt động dưới dạng một extension độc lập chỉ chèn CSS sửa font, bạn **không cần chỉnh sửa file của extension Muse gốc** và **không bị mất khả năng tự động cập nhật** từ Chrome Web Store.

## Hướng dẫn cài đặt (Chrome / Cốc Cốc / Edge)

1. **Tải về và giải nén**
   - Bấm nút **Code** (màu xanh) ở góc trên bên phải trang GitHub này → chọn **Download ZIP**.
   - Giải nén file `.zip` vừa tải về vào một thư mục cố định trên máy (ví dụ: `D:\muse-vietnamese-font-fix`).

2. **Bật chế độ nhà phát triển**
   - Mở trang quản lý tiện ích mở rộng của trình duyệt:
     - Chrome: `chrome://extensions`
     - Cốc Cốc: `coccoc://extensions`
     - Edge: `edge://extensions`
   - Bật công tắc **Chế độ nhà phát triển** (**Developer mode**).

3. **Cài đặt tiện ích**
   - Bấm **Tải tiện ích đã giải nén** (**Load unpacked**).
   - Chọn thư mục vừa giải nén (thư mục có chứa file `manifest.json`) là xong. Tải lại trang Muse hoặc mở lại Side Panel để thấy thay đổi.
